
# CodeAlpha - Login and Registration System

## Project Description
A Login and Registration System developed using C++.

## Features
- User Registration
- User Login
- Username Validation
- Duplicate Username Detection
- File Handling
- Success and Error Messages

## Technologies Used
- C++
- File Handling
- String Handling

## How to Run

Compile:
g++ userlogin.cpp -o userlogin.exe

Run:
.\userlogin.exe
